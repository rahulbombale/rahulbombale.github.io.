# Rahul Bombale — Portfolio Website

A responsive, static portfolio website built with HTML, CSS, and JavaScript.

## Before publishing
1. Open `index.html`.
2. Replace `YOUR_EMAIL@example.com` with your real email address.
3. Replace the LinkedIn link with your public LinkedIn profile URL.
4. Replace the GitHub link with your GitHub profile URL.
5. Check every project description and add repository/demo links only when they are publicly viewable.
6. Do not upload passwords, API keys, `.env` files, or private company data.

## Publish free with GitHub Pages
1. Sign in to https://github.com/ and create a new **public** repository named exactly `your-github-username.github.io` (replace with your GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait a few minutes. Your public website address will be:
   `https://your-github-username.github.io/`

The final URL works only after you create the repository and GitHub Pages publishes it. Replace the placeholder username with your actual GitHub username.
